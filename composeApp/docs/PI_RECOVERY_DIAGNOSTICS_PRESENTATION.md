# Desktop recovery diagnostic presentation v1

The JVM-only Compose panel displays a stable headline and operator instruction derived from the validated Recovery Diagnostics DTO v1. BLOCK and malformed DTOs fail closed; REQUIRE_OPERATOR always requires operator investigation, and VALIDATE_FOR_MANUAL_REVIEW still requires manual review and separate approval. Raw exception/path contents must not be echoed in UI copy.

The existing diagnostic codes remain available below the human-readable guidance. This is read-only presentation: no automatic lock removal, retry, resume, connection to PI controller or mechanical motion.
