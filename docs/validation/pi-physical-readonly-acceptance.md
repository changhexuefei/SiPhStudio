## 2. 前置条件和禁令

- 确认操作员有现场设备操作授权，已核对控制器型号、六轴装置与网络服务配置；默认 TCP 端口 `50000` 仅作输入示例，必须以设备配置为准。
- 操作员确认机械区域清空、急停可用、设备无未处理报警。**此验收禁止发送 Move、Jog、Servo On、Home、Reference、Stop 等动作命令**，只验证 Connect、`*IDN?`、`POS?`、Disconnect。
- 测试不要求控制器 Ready，更不能由成功读取位置推断轴已停止；六轴实际坐标应与控制器原生界面或已知只读参考值核对。
- 如果出现异常运动、机械干涉风险或安全报警，立即遵循现场设备安全程序，**终止本验收**；不能仅靠本应用的 Disconnect 代替急停。

## 4. 证据要求

推荐将现场证据保存至独立、受控的验证记录系统，不提交含 IP、序列号、人员信息或设备机密的未脱敏日志。至少包括：

1. 软件 commit、测试日期、控制器/固件配置、现场人员签字或复核信息；
2. 按步骤保存脱敏的连接状态截图、`*IDN?` 与六轴位置显示、Disconnect 后界面；
3. 记录原生设备界面的只读参考值以及线性 mm → µm 单位核算；
4. 标注每项 PASS/FAIL/SKIP，异常日志及处置，保留完整失败证据；
5. 标注 **仅只读通讯验收**，不等同于运动安全验收或量产授权。
